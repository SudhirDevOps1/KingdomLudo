# Design System — Royal Enchanted Courtyard

## Color Tokens (`src/index.css` & `src/config/appConfig.ts`)
| Token | Hex | Usage |
| :--- | :--- | :--- |
| Royal Obsidian | `#10141E` | Primary app background & recessed panels |
| Structural Slate | `#1A2130` | Elevated cards, drawers, and modals |
| Ivory | `#E7E2D8` | Primary typography & high-contrast foreground |
| Royal Gold | `#E6A93C` | Primary CTAs, active highlights, focus rings |
| Sovereign Gold | `#D97706` | Hover state & Yellow Kingdom primary |
| Crimson | `#DC2626` | Red Kingdom & destructive actions |
| Cobalt | `#2563EB` | Blue Kingdom & multiplayer actions |
| Emerald | `#16A34A` | Green Kingdom & ready/success confirmations |

## Typography
- **Display (`font-display`)**: `Cinzel`, Georgia, serif — screen headers, kingdom names, victory titles.
- **UI Body (`font-sans`)**: `Plus Jakarta Sans`, system sans-serif — menus, labels, rules, descriptions.
- **Monospace (`font-mono-num`)**: `JetBrains Mono` with `tabular-nums` — 6-character room codes, scores, countdown timers, and health latency.
