# Project Roadmap

## Phase 1 — Core Platform (Completed)
- Deterministic 15x15 Ludo engine & 3-tier AI opponents.
- Three.js Royal Enchanted Courtyard + 5 selectable environments.
- 12 procedural 3D characters, customization wardrobe, and optional GLB loader.
- Express + WebSocket authoritative multiplayer (private rooms & public matchmaking).
- IndexedDB offline persistence, Firebase Auth/Firestore integration, and 5-adapter DB layer.
- Automated Vitest suite, PWA build, Capacitor Android configuration, and GitHub Actions workflows.

## Phase 2 — Future Enhancements (Planned Backlog)
- External artist-sculpted `.glb` skeletal character packs wired through `optionalGlbPath`.
- Multi-node Redis adapter for horizontal WebSocket room scaling.
- Seasonal ranked leaderboard seasons backed by PostgreSQL materialized views.
- Native Play Games Services / Google Sign-In Capacitor plugin integration for Android AAB distribution.
